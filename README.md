# AI Task Master: Агент оптимизации планирования

Task Master AI — это интеллектуальный агент, который помогает справиться с когнитивной перегрузкой. Он превращает неструктурированный «поток сознания» пользователя в четко приоритизированную матрицу Эйзенхауэра в формате Excel.

### Что делает этот агент:

1. **Извлечение смыслов:** Анализирует текст и отделяет реальные задачи от эмоционального контекста.
2. **Работа с датами (Tool 1):** Использует инструмент get_current_time, чтобы сопоставить дедлайны (например, "завтра" или "в пятницу") с текущей датой.
3. **Оптимизация (Track D):** На основе анализа срочности и важности распределяет задачи по 4 квадрантам.
4. **Сохранение (Tool 2):** Экспортирует результат в файл matrix.xlsx через инструмент save_tasks_to_matrix.

## Стек

- **LLM:** GigaChat выбран для работы без прокси и нативной поддержки инструментов.
- **Стек:** Python, GigaChat SDK.
- **Инструменты:** openpyxl (Excel), python-dotenv (ENV).

## Структура проекта

- main.py — точка входа, CLI-интерфейс и сравнение с Baseline решением.
- agent.py — «мозг» агента, реализующий цикл (Reasoning Loop) и логику работы с GigaChat.
- tools.py — описание и реализация инструментов (время и работа с Excel).
- REFLECTION.md — подробный разбор процесса разработки, успехов и failure cases.
- requirements.txt — список зависимостей.


## Пример работы

**Запрос:**

> "Привет! Мне нужно доделать проект к среде, еще купить корм коту сегодня, а то он голодный. И вообще я так устал от всего этого, хочу в отпуск."

**Действия агента:**

1. Вызывает get_current_time, узнает, что сегодня понедельник.
2. Анализирует:
    - "Доделать проект" -> Квадрант 1 (Срочно/Важно), так как дедлайн через 2 дня.
    - "Купить корм" -> Квадрант 3 (Срочно/Не важно), бытовая задача.
    - "Устал/Отпуск" -> Фильтрует как эмоциональный контекст.
3. Вызывает save_tasks_to_matrix и записывает всё в matrix.xlsx.
