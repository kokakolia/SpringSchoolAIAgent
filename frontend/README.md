# До дедлайна — интерфейс

Статические HTML/CSS/ES-модули в `dist/`, без сборки. Основной экран — `index.html`, первоначальный прототип матрицы сохранён как `matrix.html`.

Запустите FastAPI из корня репозитория (`.\scripts\run-local.ps1` в Windows), откройте `http://127.0.0.1:8000`. Интерфейс автоматически использует API на том же origin. Подробности запуска и ключей — в корневом README.

При отдельном статическом размещении открывается демонстрационный сценарий. Параметр `?demo=1` явно включает его и на локальном сервере. Демо обозначено в интерфейсе, не выполняет вызовов AI и использует localStorage `deadline.showcase.v2`. Обновлённая опубликованная версия также работает как демо; ключи и локальная БД туда не передаются.

Реальный режим поддерживает создание и редактирование проектов, обсуждение и пересчёт плана, сравнение версий, принятие, закрепление и завершение задач с фактическим временем, историю событий, подсчёт и сжатие памяти, восстановление контекста. Схемы и ограничения описаны в `docs/planning-api.md` корня репозитория.

Шрифт Manrope загружается с Google Fonts. При недоступной сети используется системный шрифт. Основные взаимодействия доступны с клавиатуры; на мобильном экране чат открывается звездой, память — кнопкой рядом.

Правая панель чата фиксирована на всю высоту экрана. Полосы прокрутки скрыты; прокрутка колёсиком, касанием и клавиатурой сохранена. Отправленное сообщение появляется немедленно, а после сохранения на сервере заменяется записью из истории без дубликата. Ошибка оставляет сообщение видимым и позволяет повторить запрос. Набранный во время ожидания текст не стирается при получении ответа.

Незаполненная до конца форма нового проекта автоматически сохраняется в localStorage текущего браузера на 24 часа с последнего изменения. Все поля восстанавливаются после закрытия формы и перезагрузки; после успешного создания проекта черновик очищается. Редактирование существующего проекта не перезаписывает черновик нового.

Проверки хранилища черновиков без зависимостей: `node --test frontend/tests/drafts.test.mjs` из корня репозитория. Черновики не синхронизируются между устройствами или разными адресами приложения.

Основной список показывает принятый план даже при наличии нового предложения; сравнение находится во вкладке «Изменения». Завершение и закрепление обновляют элементы без пересоздания списков и чата, без общего индикатора запроса. Плашка принятия появляется только при изменении работы: задач, оценок, приоритетов, зависимостей, критериев, требований или резерва. Обновлённые объяснения не требуют повторного принятия. Уведомление «План принят» можно закрыть; выбор сохраняется в браузере отдельно для каждой версии проекта.

Все тесты интерфейса: `node --test frontend/tests/*.test.mjs`.

Меню «⋯» у проекта и в заголовке позволяет переименовать или удалить проект. Переименование не требует повторного заполнения условий. Перед удалением показывается подтверждение с названием; удаляется только выбранный проект. После удаления последнего проекта чат очищается и появляется пустой экран. В статическом демо переименование и удаление сохраняются в браузере; кнопка «Открыть пример» восстанавливает демонстрационный проект.
