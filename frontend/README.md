# Мой план лучше — интерфейс

HTML/CSS и ES-модули в `dist/`, без сборки и клиентских зависимостей.
Запуск из корня: `.\scripts\run-local.ps1` или `python main.py serve`.
Интерфейс использует API на том же origin. Старый прототип матрицы удалён.

При статическом размещении работает подготовленный сценарий без AI. `?demo=1`
включает его явно. Состояние примера сохраняется в localStorage `deadline.showcase.v2`;
ключи модели и серверная база в статическое демо не попадают. Свободное обсуждение,
создание проектов и память работают в настоящем приложении.

Правый чат занимает всю высоту экрана. Полосы прокрутки скрыты, прокрутка сохранена.
Сообщение появляется сразу; сбой позволяет повторить его с сохранением идентификатора.
Занятость агента не считается конфликтом правок. Принятый план остаётся доступным,
пока обсуждается новое предложение. Повторно принимать тот же состав работ не нужно.

Черновик формы сохраняется на 24 часа с последней правки. Черновики сообщений
отдельные для каждого проекта, также хранятся 24 часа; сохранение ограничено 30 проектами.
Они восстанавливаются при переключении и перезагрузке, очищаются после отправки
или удаления проекта. При недоступном хранилище текст сохраняется в текущем сеансе.
Данные браузера не синхронизируются между устройствами или адресами приложения.

На телефоне доступны переключатель проектов, создание, память и чат. Ошибки
условий проекта показываются внутри формы. Все пользовательские тексты экранируются.
Шрифт Manrope загружается с Google Fonts, при недоступности используется системный.

Основные файлы: deadline.js — действия и отображение, api.js — сетевые ошибки
и тайм-ауты, composer.js/drafts.js — черновики, view-state.js — состояние плана,
dom.js — обновление без потери фокуса и прокрутки, demo.js — сценарий без сервера.

Проверки: `node --test frontend/tests/*.test.mjs` из корня репозитория.
