# Сценарий показа

1. Создать проект «Подготовить приложение для портфолио»: рабочий показ одного сценария,
   понятный README, объяснение архитектуры и ограничений; задать дедлайн и доступное время.
2. Получить план, открыть причины и критерии готовности задач.
3. Возразить: «Анимации важны для показа. Их нужно сохранить»; закрепить соответствующую задачу.
4. Сообщить о потере часа. Сравнить варианты: что упрощено, что отложено и с какими потерями.
5. Принять подходящий план, завершить первый шаг с фактическим временем.
6. Открыть память: посмотреть размер, версии сжатия и возможность восстановления.
7. Перезагрузить страницу: принятый план, журнал и прогресс сохраняются.

Что демонстрирует проект: полный путь от идеи до работающего продукта, структурированный
вывод модели, проверку решений кодом, постоянную память и управление контекстом,
контроль пользователя и обработку ошибок. Историю разработки и принятые решения
следует объяснять своими словами, показывая реальные ограничения и компромиссы.

Статическое демо воспроизводит подготовленный сценарий без AI. Для свободного обсуждения
нужен локальный запуск с YandexGPT. Оценки модели остаются предположениями;
наличие ссылки на требование не доказывает его полное смысловое выполнение.
