# Выгрузка данных прежней версии

У проекта один интерфейс и API проектов. Старые экран матрицы, API CRUD,
экспорт Excel и цикл инструментов удалены. `/api/process` возвращает `410 Gone`.
Таблица `tasks` оставлена для сохранности данных и совместимости миграций;
приложение её не изменяет.

Если в прежней версии были задачи, их можно прочитать в JSON:

```bash
python main.py legacy-export --output legacy-tasks.json
```

Команда использует DATABASE_URL из `.env`. Файл содержит все прежние строки,
включая user_id, название, квадрант, обоснование и дату. Выгрузка не переносит
их в проекты автоматически и не удаляет их из базы. Текст остаётся буквальными
значениями JSON; формулы таблиц не создаются.
